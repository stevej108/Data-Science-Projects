# CMS Medicare Utilization Analytics

A healthcare claims analytics project built using CMS DE-SynPUF synthetic Medicare data.

The project transforms multi-grain Medicare claims into a validated longitudinal beneficiary-year analytical layer and examines:

- healthcare utilization across care settings
- Medicare cost concentration
- chronic-condition burden
- longitudinal high-cost persistence
- payer-oriented member segmentation
- inpatient, outpatient, professional, and prescription utilization

A major emphasis is placed on analytical validation, including claim-grain validation, beneficiary linkage, merge-cardinality testing, duplicate detection, and financial reconciliation.

## Featured Analysis

The final framework identifies six interpretable member segments ranging from persistent high-cost complex beneficiaries to stable/lower-utilization members, demonstrating how longitudinal claims analytics can provide substantially more context than a single annual high-cost indicator.
